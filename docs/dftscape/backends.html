dftscape.backends

DFTScape Backends Package

The backends package provides a unified interface for computational engines in DFTScape. It supports quantum chemistry calculations, testing frameworks, and custom implementations through a pluggable architecture.

The package implements the Backend protocol, allowing seamless integration of different computational methods while maintaining consistent APIs for energy, gradient, and Hessian calculations.

Available Backends

Built-in Backends: - Psi4Backend: Production quantum chemistry using Psi4 - TestBackend: Analytical test functions for algorithm validation

Quick Start

Using Built-in Backends:

>>> from dftscape.backends import BackendRegistry
>>>
>>> # Create a Psi4 backend
>>> backend = BackendRegistry.create("psi4",
...     cmp_mthd="b3lyp/6-31g*",
...     memory="2GB",
...     num_threads=4,
...     molecule_xyz="3\n\nO 0.0 0.0 0.0\nH 0.757 0.586 0.0\nH -0.757 0.586 0.0",
...     molecule_directives={"charge": 0, "multiplicity": 1}
... )
>>>
>>> # Use for calculations
>>> coords = np.array([0.0, 0.0, 0.0, 0.757, 0.586, 0.0, -0.757, 0.586, 0.0])
>>> energy = backend.compute_energy(coords.flatten())
>>> gradient = backend.compute_gradient(coords.flatten())

Implementing Custom Backends

DFTScape supports custom backend implementations through the Backend protocol. This enables integration of specialized computational methods like machine learning interatomic potentials, force fields, or proprietary quantum chemistry codes.

Backend Protocol Requirements

All backends must implement the Backend protocol with these methods:

  1. compute_energy(state: np.ndarray) -> float

    • Compute potential energy for given coordinates
    • state: 1D array of shape (3*N,) for N atoms [x1,y1,z1,x2,y2,z2,...]
    • Returns: Energy value (float)

  2. compute_gradient(state: np.ndarray) -> np.ndarray

    • Compute nuclear gradients (first derivatives)
    • state: Same format as compute_energy
    • Returns: Gradient array of shape (3*N,)

  3. compute_hessian(state: np.ndarray) -> np.ndarray

    • Compute nuclear Hessian (second derivatives)
    • state: Same format as compute_energy
    • Returns: Hessian matrix of shape (3N, 3N)

  4. get_xyz(state: np.ndarray) -> str

    • Export coordinates in XYZ format
    • state: Same format as compute_energy
    • Returns: XYZ format string

...     geometry optimization.
...     """

...                  **kwargs):

...         Initialize ML-IAP backend.

...             model_path: Path to trained ML model

...         self.device = device

...         # For this example, we'll use a placeholder
...         self.model = None
...         print(f"ML-IAP Backend initialized with {len(atomic_numbers)} atoms")
...
...     def compute_energy(self, state: np.ndarray) -> float:
...         """
...         Compute energy using ML-IAP model.
...
...         Args:
...             state: 1D array of coordinates [x1,y1,z1,x2,y2,z2,...]
...
...         Returns:
...             float: Predicted energy in atomic units
...         """
...         # Reshape coordinates to (N, 3)
...         coords = state.reshape(-1, 3)
...         n_atoms = len(coords)
...
...         # In real implementation:
...         # energy = self.model.predict_energy(coords, self.atomic_numbers)
...
...         # Placeholder: simple harmonic potential
...         energy = 0.0
...         for i in range(n_atoms):
...             r = np.linalg.norm(coords[i])
...             energy += 0.5 * r**2  # Harmonic potential
...
...         return float(energy)
...
...     def compute_gradient(self, state: np.ndarray) -> np.ndarray:
...         """
...         Compute gradients using ML-IAP model.
...
...         Args:
...             state: 1D array of coordinates
...
...         Returns:
...             np.ndarray: Gradient array of shape (3*N,)
...         """
...         coords = state.reshape(-1, 3)
...         n_atoms = len(coords)
...
...         # In real implementation:
...         # forces = self.model.predict_forces(coords, self.atomic_numbers)
...         # return -forces.flatten()  # Convert forces to gradients
...
...         # Placeholder: gradient of harmonic potential
...         gradient = np.zeros_like(state)
...         for i in range(n_atoms):
...             r = np.linalg.norm(coords[i])
...             if r > 0:
...                 grad_i = coords[i] / r  # Unit vector
...                 gradient[3*i:3*i+3] = grad_i
...
...         return gradient
...
...     def compute_hessian(self, state: np.ndarray) -> np.ndarray:
...         """
...         Compute Hessian matrix.
...
...         For ML-IAP models, analytical Hessians may not be available.
...         Consider using finite differences or numerical differentiation.
...         """
...         # Many ML-IAP models don't provide analytical Hessians
...         # Use finite differences as fallback
...         return self._finite_difference_hessian(state)
...
...     def _finite_difference_hessian(self, state: np.ndarray,
...                                   h: float = 1e-5) -> np.ndarray:
...         """
...         Compute Hessian using finite differences.
...
...         Args:
...             state: Coordinate array
...             h: Finite difference step size
...
...         Returns:
...             np.ndarray: Hessian matrix
...         """
...         n = len(state)
...         hessian = np.zeros((n, n))
...         grad_0 = self.compute_gradient(state)
...
...         for i in range(n):
...             state_plus = state.copy()
...             state_plus[i] += h
...             grad_plus = self.compute_gradient(state_plus)
...             hessian[i] = (grad_plus - grad_0) / h
...
...         # Make symmetric
...         hessian = (hessian + hessian.T) / 2
...         return hessian
...
...     def get_xyz(self, state: np.ndarray) -> str:
...         """
...         Generate XYZ format string.

...         coords = state.reshape(-1, 3)
...         n_atoms = len(coords)
...
...         lines = [str(n_atoms), "ML-IAP Generated"]
...         for i in range(n_atoms):

...             x, y, z = coords[i]
...             lines.append("12.6f")
...
...         return "\n".join(lines)

Best Practices for Custom Backends

  1. Error Handling:

    • Validate input dimensions and coordinate formats
    • Handle model loading failures gracefully
    • Provide informative error messages

  2. Performance Optimization:

    • Cache expensive computations when possible
    • Use appropriate data types (float32 vs float64)
    • Consider batched operations for multiple evaluations

  3. Coordinate Systems:

    • Always work with flattened 1D arrays internally
    • Convert to 3D arrays (N, 3) for calculations
    • Maintain consistent units (Angstroms for coordinates)

  4. Memory Management:

    • Clean up large data structures when done
    • Use memory-efficient data structures
    • Consider streaming for large systems

  5. Testing and Validation:

    • Test against known analytical systems
    • Validate gradient/Hessian consistency
    • Check energy conservation in dynamics

  6. Documentation:

    • Document all parameters and their units
    • Provide usage examples
    • Explain limitations and assumptions

This protocol defines the interface that all quantum chemistry computational backends must implement to be used within the DFTScape framework. It provides a unified API for energy calculations, gradient computations, Hessian matrix evaluation, and molecular geometry handling.

The Backend protocol abstracts the specific quantum chemistry package or method being used, allowing DFTScape to work with different computational engines (Psi4, Gaussian, ORCA, etc.) through a consistent interface.

Key Methods:

  • Coordinate arrays should be 1D with shape (3*N,) for N atoms

  • Gradients should be 1D arrays with shape (3*N,) in atomic units

464    def compute_hessian(self, state: np.ndarray) -> np.ndarray:
465        """
466        Compute the analytical nuclear Hessian matrix at the given molecular geometry.
467
468        Calculates the second derivatives of the electronic energy with respect
469        to nuclear coordinates using analytical quantum chemistry methods.
470        The Hessian matrix provides curvature information essential for
471        transition state finding and vibrational analysis.
472
473        The Hessian eigenvalues determine the nature of stationary points:
474        - All positive: minimum (stable structure)
475        - One negative: transition state (first-order saddle)
476        - Multiple negative: higher-order saddle or unstable structure
477
478        Args:
479            state: 1D numpy array of nuclear coordinates with shape (3*N,),
480                  where N is the number of atoms. Coordinates in Angstroms,
481                  ordered as [x1, y1, z1, x2, y2, z2, ...].
482
483        Returns:
484            np.ndarray: Nuclear Hessian matrix with shape (3*N, 3*N).
485                       Elements are d²E/dx_i dx_j in Hartree/Angstrom² units.
486                       Symmetric matrix representing energy curvature.
487
488        Raises:
489            RuntimeError: If Psi4 Hessian calculation fails.
490            ValueError: If coordinate array has incorrect dimensions.
491
492        Examples:
493            >>> # Calculate Hessian at equilibrium geometry
494            >>> coords = np.array([0.0, 0.0, 0.0, 0.757, 0.586, 0.0, -0.757, 0.586, 0.0])
495            >>> hessian = backend.compute_hessian(coords)
496            >>>
497            >>> # Analyze stationary point character
498            >>> eigenvals = np.linalg.eigvals(hessian)
499            >>> n_negative = np.sum(eigenvals < 0)
500            >>> print(f"Number of negative eigenvalues: {n_negative}")
501            >>> if n_negative == 0:
502            ...     print("Minimum (stable structure)")
503            ... elif n_negative == 1:
504            ...     print("Transition state")
505            ... else:
506            ...     print("Higher-order saddle")
507            >>>
508            >>> # Calculate harmonic vibrational frequencies
509            >>> # (eigenvalues of Hessian give frequencies squared)
510            >>> frequencies = np.sqrt(np.abs(eigenvals)) * 5140.48  # cm⁻¹
511            >>> print(f"Vibrational frequencies: {frequencies} cm⁻¹")
512
513        Notes:
514            - Provides analytical Hessian (exact second derivatives)
515            - Most computationally expensive calculation
516            - Hessian is always symmetric by construction
517            - Eigenvalue analysis determines stationary point type
518            - Essential for transition state characterization
519            - Can be used for vibrational frequency calculations
520        """
521        import psi4  # type: ignore
522
523        self._set_state(state)
524        kwargs: Dict[str, Any] = {"return_wfn": True, "molecule": self.molecule}
525        hess: Any
526        hess, self.wfn = psi4.hessian(self.cmp_mthd, **kwargs)
527        return np.asarray(hess.to_array(), dtype=float)
